`grilling` keeps only the methodology and the question-craft, and defers the round's mechanical details to the tool's own description: field semantics, the wordings the tool rejects, and the shape of the answer block. The tool description is the runtime contract, so the skill body no longer follows every field change, and a harness that has the tool but not this skill still gets the rules.
